W1 Formula Construct Adapt SSI v4.0.2 formula from European baseline to Sweden. Calibrate winter storm parameters (κ_winter 1.0–1.35, dominant in north), arctic thermal effects (κ_thermal 0.85–1.02, Arctic preservation in Norrbotten/Västerbotten, temperate in Skåne), nuclear proximity weighting for Forsmark (3 reactors, ~3.2 GW), Ringhals (2 reactors, ~1.7 GW), Oskarshamn (1 reactor, ~1.5 GW). Map all 95 variables to Swedish data sources. Define 2 hazard zones (Stable interior/Northern Arctic), 4 corrosion classes (C1–C4 using SMHI air quality + Baltic coastal distance). DONE CRITICAL None
W2 Data Input List Map all 95 variables to ~30 Swedish data sources with resolution, frequency, access method, join keys. Priority sources: Svenska kraftnät, Energimarknadsinspektionen (Ei), SCB (Statistiska centralbyrån), SMHI (Sveriges meteorologiska och hydrologiska institut), SGU (Sveriges geologiska undersökning), Naturvårdsverket (Swedish EPA), SSM (Strålsäkerhetsmyndigheten), OSM, Copernicus. Result: all 95 variables mapped; ingestion pipeline operational. DONE CRITICAL W1
W3 Source Access Verification Deploy source modules for Sweden (d01_svenskakraftnät, d02_energimarknadsinspektionen, d03_scb, d04_smhi, d05_sgu, d06_naturvårdsverket, d07_copernicus). Test API connectivity (Svenska kraftnät Open Data, Ei portal, SCB Data Portal, SMHI Open Data, SGU WMS). Set up CI/CD for monthly ingestion. Map all sources via SSI_VARIABLE_MAP. Result: all source modules verified and connected. DONE CRITICAL W2
W4 OSM Power Graph Extract Run Overpass API for Sweden: power=substation (nodes) + power=line (edges) for 110 kV+. Build NetworkX topology. Assess OSM coverage (expected 85% for Sweden, excellent Nordic mapping). Compute degree, betweenness centrality, bridge detection. Account for regional DSO boundary effects. Map 4 bidding zones (SE1–SE4, north to south). Result: 3,872 substations + 20,877 power lines extracted; graph topology computed (degree, betweenness, clustering, bridge detection). DONE HIGH W3
W5 Fleet Inventory Build Build master substation inventory from OSM + Svenska kraftnät supplement. Assign: substation_id (SE_*), lat/lon, Län (21 counties), Kommun (290 municipalities), bidding zone (SE1–SE4), DSO operator, voltage class, vintage estimate from OSM start_date. Cross-validate count with Svenska kraftnät and regional DSO registries. Result: 3,872 substations across 21 Län, 4 bidding zones (SE1–SE4), voltage 110–500 kV. DONE HIGH W4
W6 Layer A — Core Metrics Ingest 20 core SSI metrics (C1–C6, V1–V3, I1–I9, E1–E2, S1, T1) from Svenska kraftnät, Energimarknadsinspektionen, SCB, SMHI. Compute normalised values. Assign to each substation via Län/Kommun/bidding zone geographic join. Result: all 6 components (C, V, I, E, S, T) populated for 3,872 substations. DONE HIGH W5, W3
W7 Layer B — Grid Telemetry Compute 19 grid telemetry variables (B.1–B.3). Apply IEEE C57.91, CIGRÉ TB 761 for transformer aging. Use vintage + SMHI temperature norms + regional κ_thermal (Skåne coast 1.02, Central Sweden 0.95, Arctic Norrbotten/Västerbotten 0.85–0.88). Account for cold preservation effect on polar equipment and Nordic HVDC technology (ABB/Hitachi Energy heritage). Result: 5 modifiers computed (R3_C_mult, R4_F_topo, R6_restoration, R6_seismic, R7_cyber) for all 3,872 substations. DONE HIGH W5, W6
W8 Layers C–E — Socio/Environmental/Open Data Ingest socio-economic (9 vars from SCB), environmental hazards (7 vars from SMHI/SGU/Naturvårdsverket), open data (8 vars from Svenska kraftnät/Ei/IEO). Total 24 variables. Result: socio-economic layer complete (population, GDP, unemployment, EP_rate, elderly_pct, rd_pct_gdp, migration_score, nuclear_proximity); transition layer complete (T1, solar/wind/hydro MW, EV share, DER ratio, renewable_pct). DONE HIGH W5, W3
W9 Layer H — Winter Storm/Flood & Hazards Download SMHI storm data and historical winter event records. Retrieve Naturvårdsverket flood risk maps. Compute area-weighted hazard exposure per substation. Assign hazard zone (Stable interior/Northern Arctic). Compute R6_hazard. Assign ISO 9223 corrosion class (C1–C4 using SMHI air quality + coastal distance to Baltic). Extract winter storm intensity (dominant hazard in north), flood risk, snow/ice loading, spring flooding records. Account for hydro dependency (40% generation) and HVDC interconnect risks. Result: seismic zones assigned (PGA values), R6_seismic computed, corrosion classes assigned per Markov model for all 3,872 substations. DONE HIGH W5
W10 Layers F & I — Markov Model Calibrate CIGRÉ TB 761 base transition matrices for 5 age cohorts. Apply environmental shift matrices (κ_winter, κ_flood, κ_thermal, κ_nuclear). Emphasize κ_winter (whole-Sweden applicability, 1.0–1.35 range with northern dominance) and κ_thermal (arctic preservation effect: colder regions age slower). Compute risk_score, π_critical, ETTC, p_crit_20yr. Result: Markov chains calibrated — risk_score, ettc_years, p_critical_20yr, corrosion_class, steady_state computed for all 3,872 substations. DONE HIGH W7, W9
W11 Monte Carlo Engine Run 10,000 MC iterations per substation with 95-dimensional Gaussian copula (vectorized NumPy). Cholesky decomposition. Compute R_median, CI=[P5,P95], P_critical. Apply deterministic modifiers (κ_winter, κ_nuclear, κ_thermal) within each iteration. Account for DSO operational differences and bidding zone fragmentation (SE1–SE4 create internal price differences). Result: 38,720,000 total MC simulations (3,872 × 10,000); R_median, R_P5, R_P95, CI_width, P_critical, skewness computed. DONE HIGH W6–W10
W12 Validation & QA Run validation checks: winter storm gradient consistency (north-south), nuclear proximity weighting (Forsmark/Ringhals/Oskarshamn), DSO boundary coherence, temperature gradient (Skåne coast to Norrbotten Arctic), flood risk zone assignment, HVDC interconnect exposure (Fenno-Skan to Finland, Konti-Skan/Baltic Cable to Denmark/Germany, NordBalt to Lithuania, SwePol to Poland, AC interconnects to Norway). Cross-validate against Svenska kraftnät adequacy reports, Ei capacity assessments. Verify κ_thermal cold-preservation calibration. Result: classification bands assigned (Critical/High/Medium/Low/Excellent), confidence tiers (high/medium/low), alert flags, climate trajectories, fleet percentiles computed. DONE HIGH W11
W13 ssi-metadata.js Create Sweden-specific metadata JS with fleet stats, institution registry, data source metadata, component weights, band calibration. Sweden-specific fields: 21 Län, 290 Kommuner, 4 bidding zones (SE1–SE4), 2 hazard zones, 4 corrosion classes, 3 nuclear power plants (6.4 GW total), winter storm intensity classification, arctic thermal modifier, hydro dependency flag (40%), HVDC interconnect topology. Result: ssi-metadata.js deployed (31,752 bytes) with fleet stats, 21 regions, band calibration. DONE MEDIUM W11
W14 Dashboard HTML Pages Create 7 HTML pages in /sweden/ folder: index.html, regional.html, intelligence.html, data.html, methodology.html, map.html, esg-report.html. Regional: 21 Län + 4 bidding zones + DNO territories. All use shared CSS/JS from parent. Result: all 7 pages deployed — index, regional, intelligence, data, methodology, map, esg-report. DONE MEDIUM W13
W15 Intelligence Page Create intelligence.html with: Sweden fleet overview, top-risk substations (winter storm zones, nuclear proximity, HVDC exposure), regional comparison radar, arctic thermal analysis, winter resilience spotlight, nuclear safety integration forecast, hydro stability assessment, bidding zone analysis. Plan monthly updates aligned with SMHI seasonal forecasts. Result: intelligence.html deployed (117 KB) with full analytical content. DONE MEDIUM W12, W14
W16 Deploy & QA Push to GitHub Pages. Verify script paths (../nav.js, ../ssi-engine.js, sweden/ssi-metadata.js). All pages load, world map updated, edition-config.json updated. DevTools verification per Knowledge Base §2. Result: deployed to GitHub Pages; all pages verified; ssi-data.json (10.2 MB), grid-geo.json (17.6 MB) live. DONE MEDIUM W14, W15
