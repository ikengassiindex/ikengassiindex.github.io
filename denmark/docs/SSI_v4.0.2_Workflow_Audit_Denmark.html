W1 Formula Construct Adapt SSI v4.0.2 formula from European baseline to Denmark. Calibrate North Sea coastal storm parameters (κ_winter 0.90–1.30, dominant on DK1 west coast and island grids), offshore wind integration (κ_wind 1.0–1.20, extreme generation variability with 50%+ offshore capacity), thermal winter modifiers (κ_thermal 0.95–1.05, moderate preservation in temperate maritime climate), zero nuclear weighting (0 plants, 0 GW, Risø research reactor decommissioned). Map all 95 variables to Danish data sources. Define 2 bidding zones (DK1 Jutland/Funen synchronous with Continental Europe, DK2 Zealand synchronous with Nordic/Sweden), 2 major hazard zones (North Sea coastal storm zone / Island grid fragility zone), corrosion classes C1–C4 (North Sea C4, Baltic coast C2, inland C1). DONE CRITICAL None
W2 Data Input List Map all 95 variables to ~28 Danish data sources with resolution, frequency, access method, join keys. Priority sources: Energinet (TSO), ENTSO-e (European Network reporting), Forsyningstilsynet (Danish Utility Regulator), Danmarks Statistik (statistics), DMI (Meteorological Institute), GEUS (Geological Institute), Energistyrelsen (Energy Agency), DKKV (Danish Climate Change Council), OSM, Copernicus. Scope: 5 Regioner, 98 Kommuner, 2 bidding zones (DK1/DK2), ~40 DSOs, island grids (Zealand, Funen, Bornholm). DONE CRITICAL W1
W3 Source Access Verification Deploy source modules for Denmark (d01_energinet, d02_entso_e, d03_forsyningstilsynet, d04_statistik_dk, d05_dmi, d06_geus, d07_copernicus). Test API connectivity (Energinet Open Data API, Forsyningstilsynet portal, Danmarks Statistik Data API, DMI Open Data, GEUS WMS). Set up CI/CD for monthly ingestion. Map all sources via SSI_VARIABLE_MAP. Target: OSM Overpass API progressive extraction, ERA5/Copernicus climate data, Danish socio-economic data by Kommune/Region, district heating integration data (~60% household penetration). DONE CRITICAL W2
W4 OSM Power Graph Extract Run Overpass API for Denmark: power=substation (nodes) + power=line (edges) for 110 kV+. Build NetworkX topology. Assess OSM coverage (expected 75–85% for Denmark, good Nordic mapping). Compute degree, betweenness centrality, bridge detection. Account for island grid effects (Zealand, Funen, Bornholm as semi-isolated clusters, connected via Great Belt Fixed Link, Øresund Bridge interconnect). Map 2 bidding zones (DK1: Jutland/Funen continental synchronous; DK2: Zealand Nordic synchronous). Target: ~2,000–3,500 substations 110 kV+ across both zones. DONE HIGH W3
W5 Fleet Inventory Build Build master substation inventory from OSM + Energinet supplement. Assign: substation_id (DK_*), lat/lon, Region (5: Capital, Zealand, South Denmark, Central Jutland, North Denmark), Kommune (~98 municipalities), bidding zone (DK1 or DK2), island affiliation (Jutland / Funen / Zealand / Bornholm), DSO operator (40+ operators: RADIUS Copenhagen/Zealand, N1 North Jutland, Cerius south Zealand, NOE Funen/south Jutland, KONSTANT, Energi Fyn, others), voltage class, vintage estimate. Cross-validate count with Energinet registry and DSO master data. Target fleet: ~2,000–3,500 substations mapped to 5 Regioner + 98 Kommuner. DONE HIGH W4
W6 Layer A — Core Metrics Ingest 20 core SSI metrics (C1–C6, V1–V3, I1–I9, E1–E2, S1, T1) from Energinet, Forsyningstilsynet, ENTSO-e, Danmarks Statistik, DMI. Compute normalised values. Assign to each substation via Region/Kommune/bidding zone geographic join. Include district heating proximity factor (>60% household penetration creates load damping in urban areas). Incorporate offshore wind exposure metrics (proximity to Horns Rev, Kriegers Flak, planned energy islands). DONE HIGH W5, W3
W7 Layer B — Grid Telemetry Compute 19 grid telemetry variables (B.1–B.3). Apply IEEE C57.91, CIGRÉ TB 761 for transformer aging. Use vintage + DMI temperature/humidity norms + regional κ_thermal (maritime temperate 0.95–1.05, no extreme preservation effect like Nordic north, but mild winters preserve equipment longer than continental). Account for North Sea coastal salt-spray corrosion in DK1 west coast and offshore grid connections. Include island grid topology heritage (Great Belt Fixed Link power + rail, Øresund Bridge AC interconnect create single-point failure risks for inter-island flows). Model district heating integration impact on grid load profile damping. DONE HIGH W5, W6
W8 Layers C–E — Socio/Environmental/Open Data Ingest socio-economic (9 vars from Danmarks Statistik), environmental hazards (7 vars from DMI/GEUS), open data (8 vars from Energinet/ENTSO-e). Total 24 variables. Include: district heating penetration by Kommune, renewable energy adoption (wind pct, solar capacity), migration patterns, R&D spending (cleantech hubs in Copenhagen/Aarhus). Seismic: α=0.05 (minimal, stable continental platform, no avalanche/quick clay risk). Environmental: coastal flood risk (low-lying flat terrain, North Sea storm surge exposure), soil subsidence (soft clay/sand in glacial deposits), no mountain/avalanche hazards. DONE HIGH W5, W3
W9 Layer H — North Sea Storm/Coastal & Hazards Download DMI storm data and historical winter event records (focus on North Sea coastal storms affecting DK1 west coast). Retrieve GEUS flood risk maps (low-lying terrain, sea level rise vulnerability). Compute area-weighted hazard exposure per substation. Assign hazard zone (North Sea coastal storm zone for DK1 / Island grid connectivity zone for DK2). Compute R6_hazard. Assign ISO 9223 corrosion class (C4 North Sea coast DK1, C2 Baltic DK2, C1 inland). Extract North Sea storm intensity, coastal flooding, sea level rise impact, storm surge records, offshore wind weather coupling. Model island grid fragmentation risk (Great Belt, Øresund links as critical infrastructure chokepoints). Compute modifiers R3_C_mult, R4_F_topo, R6_restoration, R6_seismic (coastal_storm), R7_cyber, R8_offshore_wind. DONE HIGH W5
W10 Layers F & I — Markov Model Calibrate CIGRÉ TB 761 base transition matrices for 5 age cohorts. Apply environmental shift matrices (κ_winter 0.90–1.30, κ_storm_coast, κ_thermal 0.95–1.05, κ_island_grid, κ_offshore_wind). Emphasize κ_winter (North Sea coastal storms, dominant in DK1 west coast) and κ_island_grid (topology fragility, single-bridge interconnect risks on Great Belt/Øresund). Compute risk_score, π_critical, ETTC, p_crit_20yr. Account for district heating grid as load damper (reduces transformer stress in urban zones). Model offshore wind variability impact on transformer aging (rapid load swings). DONE HIGH W7, W9
W11 Monte Carlo Engine Run 10,000 MC iterations per substation with 95-dimensional Gaussian copula (vectorized NumPy). Cholesky decomposition. Compute R_median, CI=[P5,P95], P_critical. Apply deterministic modifiers (κ_winter, κ_storm_coast, κ_thermal, κ_island_grid, κ_offshore_wind, κ_district_heating) within each iteration. Target: ~20,000–35,000 substations (fleet size range), generating 200M–350M total MC simulations. Compute R_median, R_P5, R_P95, CI_width, P_critical, skewness, classification bands, confidence tiers. DONE HIGH W6–W10
W12 Validation & QA Run validation checks: North Sea coastal storm gradient consistency (DK1 west coast high, inland low), island grid connectivity risk (Great Belt, Øresund critical node detection), bidding zone coherence (DK1 continental sync vs. DK2 Nordic sync), offshore wind exposure mapping (Horns Rev, Kriegers Flak, energy islands), DSO boundary coherence, corrosion class assignment (C4 coastal, C2 Baltic, C1 inland), district heating load damping effect, soil subsidence/sea level rise exposure. Validate fleet distribution across regions, classification bands, confidence tiers, alert flag system. DONE HIGH W11
W13 ssi-metadata.js Create Denmark-specific metadata JS with fleet stats, institution registry, data source metadata, component weights, band calibration. Denmark-specific fields: 5 Regioner, 98 Kommuner, 2 bidding zones (DK1/DK2), 2 hazard zones (North Sea storm / Island grid), 4 corrosion classes (C1–C4), 0 nuclear plants (0 GW), North Sea coastal storm intensity, offshore wind penetration (50%+ generation), district heating penetration (~60% households), interconnection count (5+ links: Sweden Øresund/Konti-Skan, Germany, Netherlands COBRAcable, UK Viking Link, Norway Skagerrak), island grid topology flag. Metadata output: country DK, code DK, prefix DK_, tso Energinet, version 4.0.2, total_substations 2000–3500 (range), total_departments 5, dso_count 40. DONE MEDIUM W11
