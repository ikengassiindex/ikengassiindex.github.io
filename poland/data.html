Data Advantages

Poland's dataset benefits from:
  • GUS Census 2021 (most recent comprehensive demographic data in EU)
  • IMGW open data portal (best-in-class meteorology coverage for Central Europe)
  • EU/Eurostat harmonized data (cross-national comparability)
  • ENTSO-E cross-border transparency (real-time transmission visibility)
  • PSE real-time dispatch data (generation/load transparency)

Known Data Gaps

Limitations to be aware of:
  • Substation Vintage: PRL-era (pre-1990) records incomplete; post-EU-accession (2004+) data comprehensive
  • Per-Substation Equipment Condition: DSO data restricted; using age-based proxies and DSO annual reports
  • Mining Subsidence Per-Site: WUG provides zone-level mapping; finer resolution limited to licensed operators
  • Transformer Inventory Details: Some DSOs do not publish granular transformer age/capacity data

Technical Specifications

ssi-data.json Schema

Each substation record includes: substation_id, name, location (lat/lon), voltage_kv, region, dso, vintage, components (6 risk dimensions), modifiers (5 risk adjustments), R_base, R_median, confidence intervals (CI_5/CI_95), classification (Low/Medium/High/Critical), and context (socio-economic, environmental, grid) data.

File Formats

  • ssi-data.json: 1,685 substation records in JSON array format. Each record contains R_median (primary risk metric), confidence bounds, and component breakdowns.
  • grid-geo.json: GeoJSON FeatureCollection with Województwa boundaries and substation centroids for interactive mapping.
  • ssi-metadata.js: JavaScript object containing data source registry, methodology documentation, and regional labels.
