4. Monte Carlo Simulation & Uncertainty Quantification

Simulation Parameters

  • Iterations per substation: 2,000
  • Correlation structure: 95-dimensional Gaussian copula with Cholesky decomposition
  • Vintage uncertainty: σ wider for PRL-era (pre-1990) assets; narrower for post-EU-accession (2004+)
  • Output metrics: R_median, CI_5 (5th percentile), CI_95 (95th percentile), P_critical (probability of reaching Critical band)

Data Strengths

  • GUS Census 2021: Most recent comprehensive demographic dataset in Europe; 100% substation-level granularity via voivodeship + powiat mapping
  • IMGW Open Portal: Best-in-class meteorology coverage for Central Europe; 3-hour resolution; includes extreme event warnings
  • EU Harmonization: Eurostat/ENTSO-E data enables cross-country benchmarking and standardized metrics
  • PSE Real-Time: Transparent generation/load/cross-border flows; enables dynamic risk correlation analysis

Known Limitations

  • Substation Vintage: PRL-era (1945–1989) asset commissioning dates incomplete; using installation-era proxies
  • Equipment Condition: Per-unit transformer diagnostics restricted by DSO; relying on age-based failure curves and aggregate DSO annual reports
  • Mining Subsidence Precision: WUG provides zone-level mapping; finer site-specific deformation data restricted to licensed extractors
  • Distributed Generation: Prosumer PV data from IEO registry is aggregated by commune; household-level data unavailable
